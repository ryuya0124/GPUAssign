# GPU Assign

Windows のグラフィックス設定（アプリごとの GPU 割り当て）において、バージョンアップ等で実行ファイル（EXE）のパスが変わった際にも、自動で最新パスを検出して GPU 割り当てを引き継ぐポータブルユーティリティです。

---

## 概要

Windows 10 / 11 では、「設定 > システム > ディスプレイ > グラフィックス」からアプリごとに使用する GPU（省電力 / 高パフォーマンス）を指定できます。  
しかし、LINE や Discord、Slack など、アップデートごとにバージョン番号付きのフォルダ配下（例: `app-1.0.9000/app.exe` や `bin/26.4.0/app.exe`）へ EXE が移動するアプリでは、更新のたびに手動で再登録が必要になります。

GPU Assign は、指定したディレクトリや検索ルールに基づいて最新の EXE を自動検出し、Windows のレジストリ設定（`HKCU\Software\Microsoft\DirectX\UserGpuPreferences`）を同期・維持します。

---

## 主な機能

### 1. アプリ管理と GPU 割り当て
- **インライン切り替え**: 一覧画面のドロップダウンから「システム既定 / 省電力 / 高パフォーマンス」を即座に変更可能。
- **ダイレクト編集**: 一覧のアイテムをクリックして設定ダイアログを開き、検索ルールやパスを調整可能。
- **アイコン自動取得**: Win32 EXE ファイルからの抽出、および Microsoft Store アプリの公式パッケージロゴ取得に対応。

### 2. 柔軟な探索モード
| モード | 動作 | 主な用途 |
|---|---|---|
| **最新バージョン自動検出** | 指定フォルダ配下を再帰探索し、バージョン番号が最も大きい EXE を自動選択 | LINE, Zoom などのセマンティックバージョニング形式 |
| **ワイルドカード (Glob)** | ディレクトリ名に `*` や `?` を使用可能（例: `Discord\app-*`） | Discord 等の Squirrel インストーラー形式 |
| **固定パス** | 指定した固定パスの EXE をそのまま対象 | バージョンパス変更のない通常のアプリ |
| **正規表現** | 検索パスとファイル名を正規表現パターンでフィルタリング | 特殊なディレクトリ構造のアプリ |
| **Microsoft Store** | AUMID（パッケージ識別子）で管理（ファイルパス指定不要） | Microsoft Store アプリ（フォト、ChatGPT 等） |

### 3. Windows 既存設定のインポート
- 現在の Windows グラフィックス設定に登録されているアプリを一括スキャン。
- バージョンフォルダが含まれるパスは自動的に「最新バージョン」や「Glob」ルールへ変換して取り込み可能。

### 4. ログオン時自動同期（常駐なし）
- Windows ログオンから 30 秒後にバックグラウンドで `/silent` モードを実行し、最新 EXE の検出とレジストリ更新を行って即座に終了します。常駐プロセスによるメモリ消費はありません。

### 5. レジストリのバックアップ & 復元
- 同期処理前に Windows の GPU 設定レジストリ全体を `.reg` 形式でバックアップ。いつでも過去の状態へ復元できます。

### 6. 完全ポータブル設計
- 設定ファイル (`apps.json`)、実行ログ (`sync_log.json`)、バックアップ (`backups/`) はすべて `GPUAssign.exe` と同一ディレクトリに保存されます（AppData は使用しません）。

---

## 動作要件

- **OS**: Windows 10 (バージョン 1809 以降) / Windows 11 (64-bit)
- **権限**: 管理者権限（DirectX レジストリおよびタスクスケジューラ操作のため、起動時に UAC 昇格を要求します）
- **ランタイム**:
  - **同梱版 (Self-Contained)**: 追加インストール不要
  - **非同梱版 (Framework-Dependent)**: [.NET 9 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/9.0)

## ビルドとパッケージング

### 前提条件
- .NET 9 SDK
- Visual Studio 2022 (C++ によるデスクトップ開発ワークロード) または MSBuild Tools

### ビルドコマンド
```cmd
:: Debug ビルド
build.cmd

:: Release ビルド
build.cmd release
```

### ポータブルパッケージの作成
同梱版（Self-Contained）および非同梱版（Framework-Dependent）の 2 種類を `publish/` フォルダへ出力します。

```powershell
.\Publish-Portable.ps1
```

---

## コマンドライン引数

| 引数 | 説明 |
|---|---|
| *(なし)* | 通常の GUI モードで起動します。 |
| `/silent` | GUI を表示せず、登録済みアプリの探索とレジストリ同期を実行して終了します（タスクスケジューラ用）。 |
